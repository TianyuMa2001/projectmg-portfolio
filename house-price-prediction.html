01

From prediction to defensible validation

I developed and refined a Cook County housing-price pipeline with feature engineering, preprocessing, model training and prediction export. The target is natural-log sale price; reported dollar RMSE is evaluated after transforming predictions back to prices.

My implementation compares a median baseline, Ridge regression and histogram gradient boosting. I added property-grouped and purged time holdouts, assessor-estimate ablation, quality checks, residual analysis and six automated pipeline tests.

02

The split changes the conclusion

A random holdout may contain properties also present in training. Grouping by property identifier (PIN) tests unseen properties. The 2019 holdout removes overlapping PINs from earlier training years and asks a different question: how well does the model transfer forward in time?

Random and grouped results are means across seeds 42/43/44. Time validation is one latest-year holdout. Three fixed splits are stability checks, not independent confidence intervals.

HistGB performs best on unseen-property holdouts, but Ridge performs better on the later-year holdout. I therefore distinguish a strong course-dataset result from a recommendation for future-year deployment.

03

Feature usefulness is not feature availability

Removing assessor estimates raises grouped HistGB RMSE from $67,116 to $68,366. This shows their contribution in this experiment; it does not prove those values were available before every sale.

The retrospective Most Recent Sale flag may also depend on information unavailable at prediction time. Neither time validation nor the no-estimates ablation resolves that issue. An as-of feature audit is needed before prospective use.

HistGB preserves ordinal category encoding from the original baseline, which introduces arbitrary ordering for nominal categories. Ridge uses one-hot categories and scaled numeric inputs. Error analysis and these limitations are documented alongside the results.

04

Reproduce the work

The code repository includes pinned dependencies, a training entry point, evaluation scripts and compact aggregate evidence. Six recorded tests cover split isolation, temporal purging, input contracts, nonmutating features, missing or unseen values, serialization and target/metric validity.

Supply the course CSVs separately, install the dependencies, and run the commands in the README. Datasets, fitted models and row-level predictions are not redistributed with this page.

The unlabeled downloaded test data has not been verified as the original grading set. I make no official contest score, ranking, fairness or online deployment claim.
